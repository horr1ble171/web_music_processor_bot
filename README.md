# Web Music Processor Bot

Современное веб-приложение (Telegram Web App) для быстрого и удобного редактирования метаданных MP3-файлов прямо в браузере.

## 🚀 Основные преимущества

*   **Полная клиентская обработка:** Все операции с файлами происходят на устройстве пользователя. Файлы не загружаются на сервер, что обеспечивает максимальную приватность и скорость работы.
*   **Интеграция с Telegram:** Специально оптимизировано для использования как Telegram Web App (поддержка полноэкранного режима, цветовых схем мессенджера и тактильной отдачи/вибрации).
*   **Пакетная обработка:** Возможность загружать и обрабатывать несколько треков одновременно.
*   **Умное управление тегами:** Приложение позволяет массово устанавливать обложку, имя исполнителя и название альбома, сохраняя или заменяя существующие метаданные.
*   **Современный UX/UI:** Лаконичный темный интерфейс, поддержка Drag-and-Drop, превью обложек и индикация прогресса.

## ✨ Функционал

- 🎵 **Редактирование ID3-тегов:** Изменение названия трека, исполнителя и альбома.
- 🖼️ **Работа с обложками:** Добавление или замена встроенных изображений (APIC) в MP3-файлах.
- 📥 **Массовое скачивание:** После обработки можно скачать каждый файл по отдельности или все сразу.
- 📳 **Haptic Feedback:** Приятный тактильный отклик при взаимодействии с элементами интерфейса внутри Telegram.
- 📂 **Drag-and-Drop:** Удобная загрузка файлов перетаскиванием.

## 🛠 Технологии

- **Frontend:** HTML5, CSS3 (Modern UI, CSS Variables, Flexbox/Grid).
- **JavaScript:** Vanilla JS (ES6+).
- **Библиотеки:**
  - `jsmediatags` — для чтения существующих метаданных.
  - `browser-id3-writer` — для записи новых ID3v2 тегов.
  - `Telegram Web App API` — для глубокой интеграции с мессенджером.

## 📖 Как пользоваться

1. Запустите бота: [@music_horr1ble_bot](https://t.me/music_horr1ble_bot)
2. Загрузите один или несколько MP3-файлов.
3. (Опционально) Загрузите изображение для обложки.
4. (Опционально) Укажите данные исполнителя, альбома или название трека.
5. Нажмите кнопку **"Обработать файлы"**.
6. Получите готовые файлы с обновленными метаданными!
